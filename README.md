# 我的旅行地图 · My Travel Map

每去一个地方，就用一张网页把它收藏起来：行程、照片、攻略都在自己手里，点开链接就能重游。从上海出发，持续更新。

每个目的地都是一个**完整的 HTML 单文件**，移动端适配、可直接分享链接打开；照片全部来自 **Wikimedia Commons 真实图片，不使用 AI 生图**。

## 如何新增一个目的地（复刻步骤）

1. 复制上面的提示词，替换**城市、日期、路线、交通方式**与重点板块，交给 TRAE 生成。
2. 让 TRAE 复用已有页面的样式（保持整站视觉统一），输出 HTML 单文件，命名为 `<城市拼音>.html`。
3. 真实照片从 Wikimedia Commons 下载，放到 `assets/<城市拼音>/`，在页面里用相对路径引用。
4. 在总入口 `index.html` 增加一张目的地板（封面图、标签、标题、简介、链接）。
5. 提交并推送到 `main` 分支，GitHub Pages 会自动部署，几分钟后即可访问。
